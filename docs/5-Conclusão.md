# 5 Conclusão

O projeto BTG – Best Time to Grow atingiu seu objetivo principal de desenvolver um Produto Mínimo Viável (MVP) voltado ao apoio da tomada de decisão no planejamento agrícola de pequenos produtores.

A solução desenvolvida integra informações meteorológicas obtidas por meio de serviços externos, permitindo que o usuário consulte previsões climáticas e receba recomendações básicas de plantio fundamentadas em regras agronômicas previamente definidas. Além disso, o sistema contempla funcionalidades de cadastro de usuários, gerenciamento de áreas de plantio, histórico de culturas e calendário agrícola.

Do ponto de vista acadêmico, o projeto possibilitou a aplicação prática dos conceitos estudados nas disciplinas de Gerenciamento de Projetos de Software e Desenvolvimento de Aplicações Distribuídas, envolvendo levantamento de requisitos, modelagem de processos, definição arquitetural, integração entre sistemas e desenvolvimento de funcionalidades distribuídas.

Por se tratar de um projeto universitário, não houve participação de um cliente ou parceiro real durante o desenvolvimento. Dessa forma, a validação foi realizada internamente pela equipe, considerando os requisitos definidos inicialmente e os objetivos propostos para o MVP.

Os testes realizados indicaram que a solução atende às funcionalidades essenciais previstas para a versão inicial do sistema, demonstrando a viabilidade técnica da proposta. Entretanto, foram identificadas oportunidades de evolução futura, como a ampliação da base de recomendações agronômicas, utilização de modelos preditivos mais avançados, suporte offline e integração com fontes climáticas mais robustas.

De forma geral, os resultados obtidos demonstram que a arquitetura adotada é adequada para a construção de uma plataforma de apoio à agricultura sustentável, servindo como base para futuras expansões e validações em ambientes reais.

## Feedback

Como o projeto foi desenvolvido exclusivamente para fins acadêmicos e não possui um cliente ou parceiro externo formal, não houve coleta de feedback de usuários reais durante esta etapa.

A validação do MVP foi realizada pela própria equipe de desenvolvimento, verificando o atendimento dos requisitos funcionais definidos no início do projeto. Em futuras versões, recomenda-se a realização de testes com agricultores familiares, técnicos agrícolas e profissionais do setor para obtenção de feedback real sobre usabilidade, utilidade das recomendações e impacto da solução no processo de tomada de decisão agrícola.
