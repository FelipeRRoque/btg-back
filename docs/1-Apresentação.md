# 1 Apresentação


O projeto Best Time to Grow (BTG) é uma aplicação web voltada à sustentabilidade no campo. O setor de agricultura familiar é responsável por cerca de 70% dos alimentos consumidos no Brasil, segundo o Ministério do Desenvolvimento Agrário, evidenciando sua importância estratégica. No entanto, esses produtores enfrentam uma lacuna tecnológica severa frente aos grandes latifúndios. O BTG busca democratizar o acesso à tecnologia, combatendo a vulnerabilidade de agricultores que dependem de métodos empíricos e sofrem com a falta de suporte técnico, alinhando-se aos Objetivos de Desenvolvimento Sustentável (ODS) 2 e 13 da ONU. O projeto visa otimizar o uso de recursos como água e sementes, fortalecer a economia local e promover a resiliência climática.

## 1.1 Cliente
Os clientes centrais deste projeto são o pequeno produtor e o agricultor familiar, figuras essenciais para a segurança alimentar que frequentemente enfrentam uma desigualdade no acesso a tecnologias agrícolas. Para que a solução seja efetiva, o sistema pretende atender a três perfis distintos, começando pelo Produtor Familiar, que possui idade entre 25 e 60 anos, detém vasto conhecimento prático agrícola e utiliza o smartphone como principal meio de acesso, apesar de possuir baixa ou média familiaridade tecnológica. Este usuário é responsável por cadastrar áreas de plantio, consultar recomendações e registrar as atividades realizadas no sistema. Complementarmente, o Técnico Agrícola ou Agrônomo atua na validação das regras de recomendação e na sugestão de parâmetros técnicos para garantir a base científica das orientações. Por fim, o Administrador do Sistema, garante o funcionamento operacional, a segurança dos dados e a gestão das integrações com APIs meteorológicas.

## 1.2 Problema
A realidade enfrentada por pequenos produtores e agricultores urbanos é marcada por uma vulnerabilidade técnica e informacional. Frequentemente, o manejo da terra ocorre de forma intuitiva, resultando em plantios realizados sem o suporte de dados meteorológicos atualizados ou de ferramentas estruturadas que auxiliem no planejamento eficaz do calendário agrícola. Essa carência de suporte técnico especializado reflete-se diretamente na viabilidade econômica e na sustentabilidade da atividade, uma vez que decisões tomadas sob apenas a experiência levam o produtor a não usufruir completamente da terra. A utilização sem dados de insumos e a instabilidade produtiva evidenciam a necessidade de uma solução que conecte a tecnologia da informação ao campo. Diante desse cenário, o problema central que este projeto aborda é: Como apoiar a tomada de decisão de pequenos produtores por meio de um sistema web que integre dados climáticos e recomendações básicas de plantio, reduzindo riscos e desperdícios? 

## 1.3 Objetivo do trabalho
O objetivo geral é desenvolver uma aplicação web distribuída para apoio à gestão de plantio inteligente, integrando dados meteorológicos externos e regras de recomendação agrícola para pequenos produtores. Além disso, os objetivos específicos do projeto são: desenvolver uma API para integração com serviço externo de previsão do tempo; implementar um banco de dados relacional para armazenamento de usuários, culturas e registros de plantio; criar um módulo de recomendação baseado em regras simples (estação do ano + clima previsto); aplicar metodologia ágil (Scrum) para organização e gerenciamento do projeto e desenvolver interface responsiva com foco em uso web-mobile. Ao longo do trabalho, será apresentada também uma descrição arquitetural detalhada do sistema, o que permitirá o aprofundamento técnico necessário para a viabilização da solução proposta.

## 1.4 Definições e Abreviaturas
BTG: Best Time to Grow.
API (Application Programming Interface): Interface que permite a integração com serviços externos.
ODS: Objetivos de Desenvolvimento Sustentável da ONU.
Scrum: Metodologia ágil utilizada na gestão do projeto.
Interface Responsiva: Design que se adapta a diferentes tamanhos de tela (web e mobile).
